One single-line, deadpan one-star review of an everyday essential — gravity — filed in earnest against a thing that cannot be fixed. `main.ts` writes the review to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).

> One star. Gravity works fine until you drop your phone, then it works perfectly. No customer support, no refund, no appeal process.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
